xfEditor 涂鸦（Canvas Graffiti）演示

点击工具栏的「涂鸦」按钮绘制；点击预览区中已生成的涂鸦图片可重新编辑。

语法说明

涂鸦使用 [[canvas[:align] title="..."]] ... [[/canvas]] 块语法，内容体为图片的 data URI。保存时编辑器会在 PNG 与 JPEG 之间自动选择体积更小者（JPEG 通常可缩小 60%~80% 且内容零丢失），因此文档中可能出现 data:image/png;base64, 或 data:image/jpeg;base64,：

[[canvas:center title="示例名称"]]
(data:image/jpeg;base64,/9j/4AAQ...)
[[/canvas]]
  • [[canvas]] 默认左对齐渲染
  • [[canvas:right]] 右对齐渲染
  • [[canvas:center]] 居中对齐渲染
  • [[canvas:right title="示例名称"]] 右对齐并给图片添加名称标记
  • 工具栏：撤销 / 恢复 / 画笔 / 橡皮擦 / 重置 / 清空 / 选择 / 放大 / 缩小 九个按钮紧挨成一组（按钮 30×30px、间隔 2px），其中“选择/扩展画布”已移至“清空”右侧、“放大”左侧
  • 清空画布：一键清除全部内容并把画布尺寸重置为填满绘制区；清空后仍可用“撤销 / 恢复”回退或前进
  • 选择工具（扩展画布）：点击后光标变为小手（抓取）；在画布上长按左键并拖动即按拖拽方向扩展画布——
    · 向右拖 → 向左扩展，画布内全部涂鸦内容整体右移新增的宽度；
    · 向下拖 → 向上扩展，内容整体下移新增的高度；
    · 向左拖 → 向右扩展（仅加宽，内容位置不变）；
    · 向上拖 → 向下扩展（仅加高，内容位置不变）；
    松手后光标恢复。画布超出绘制区时自动出现滚动条。
  • 画笔 / 橡皮只作画不改尺寸：绘制（含放大后绘制）过程绝不修改画布宽高，无抖动、无尺寸异常；如需改变画布大小，请使用“选择工具”拖拽扩展。
  • 画布占满绘制区：可视画布始终铺满 .xf-cg-canvas-wrap，空白区域为白底，超出时滚动查看
  • 缩放不丢内容：放大 / 缩小只改变显示比例，画布舞台之外的内容永不丢失
  • 智能裁剪 + 最小体积导出：保存时按内容包围盒自动裁剪去空白并叠加白底，再在 WebP / 多档 JPEG / PNG 中自动选择体积最小者（内容零丢失）
  • 弹窗最大化 / 恢复：支持最大化占满可视区，画布区高度 = 内容高 − 底部按钮高 − 工具栏高
