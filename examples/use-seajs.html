Using sea.js

说明：

1、xfEditor 已内置零依赖 micro-DOM，不再依赖 jQuery；在 Sea.js 下直接 seajs.use(["../xf_editor"], ...) 即可，无需为 jQuery 单独做 Sea.js 兼容包装。

2、flowChart（流程图）和sequenceDiagram（时序图）基于Raphael.js，由于疑似Sea.js与Raphael.js有冲突，所以必须先加载Raphael.js再加载Sea.js，xfEditor才能在Sea.js下正常进行；

  • Enable HTML tags decode
  • Enable TeX, Flowchart, Sequence Diagram, FontAwesome, Task lists
  • Enable Image upload
  • Enable [TOCM], Search Replace, Code fold
